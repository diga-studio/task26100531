# task26100531

`txnwindow`：时点正确的交易窗口特征库（纯进程内存，无外部依赖）。

## 功能

按账户汇总过去 24 小时（`[T-86400000ms, T)`）的交易笔数与总金额（整数分）。
同时按样本时间 T 和数据可见序号 K 还原特征：晚到、撤回、更正均只在其实际录入
序号起可见，历史截止序号的查询结果不受后续修订影响。

## 使用

```go
s := txnwindow.NewStore()

// 批量录入修订：新增 / 修正时间或金额 / 撤回（Revoked: true）/ 撤回后恢复。
// 返回全局递增的可见序号（从 1 开始），批内所有修订在该序号一起可见。
k := s.Apply([]txnwindow.Revision{
    {Account: "a1", EventID: "e1", TimeMs: t - 3600_000, Amount: 100},
    {Account: "a1", EventID: "e2", Revoked: true},
})

// 批量查询：每条查询独立指定账户、样本时间 T 与截止序号 K。
feats := s.Query([]txnwindow.Query{
    {Account: "a1", Sample: t, Cutoff: k},
})
// feats[i].Count 为笔数，feats[i].Sum 为总金额（分）；空窗口为 {0, 0}。
```

规则要点：

- 交易由 `Account + EventID` 唯一标识；不同事件 ID 即使时间金额相同也分别计数。
- 查询先取每笔交易在序号 `<= K` 时的最后修订，再判断是否参与汇总：
  未撤回，且交易时间 `>= T-86400000` 且 `< T`（UTC 整数毫秒）。
- 录入与查询可任意交替；`Store` 内部加锁，可并发使用。

## 测试

```sh
go test ./...
```

覆盖：单笔交易 新增→修正→撤回→恢复 的四个截止序号结果；晚到交易不可见、
窗口两端边界、同时间多笔交易、历史截止序号结果稳定性；空窗口与未知账户。
